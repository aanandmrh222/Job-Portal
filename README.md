# 💼 MERN Job Portal Website

A full-stack Job Portal web application built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js). The platform supports **two user roles**: **Recruiters** and **Students**, each with dedicated functionality.

---

## 🚀 Features

### 🎓 For Students
- Sign up / Log in
- Browse and search jobs
- Apply to jobs
- View applied jobs

### 🧑‍💼 For Recruiters
- Sign up / Log in
- Post new job listings
- View applicants
- Edit / Delete jobs

### 🔐 Auth & Security
- JWT-based authentication
- Role-based route protection (Student / Recruiter)

### ✅ API Testing
- Thoroughly tested using Postman
- HTTP methods tested: GET, POST, PUT, PATCH, DELETE
- Verified error handling, invalid inputs, and auth failures
